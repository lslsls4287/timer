# 🍅 뽀모타이머 (Pomodoro Timer)

집중력 향상과 효율적인 시간 관리를 위한 모던 뽀모도로 타이머 웹 애플리케이션입니다.

## ✨ 주요 기능
- **3가지 모드**: 집중(25분), 짧은 휴식(5분), 긴 휴식(15분)
- **비주얼 타이머**: 직관적인 SVG 원형 프로그레스 게이지 및 브라우저 탭 타이틀 실시간 표시
- **소리 및 알림**: Web Audio API 기반의 맑은 차임벨 완료 알림음 및 데스크톱 알림(Notification API)
- **할 일 목록(To-do List)**: 오늘의 집중 목표 체크리스트
- **세션 트래커**: 완료한 뽀모도로 세션 수 기록 (토마토 🍅 스탬프)
- **다크 / 라이트 모드**: 환경에 맞춘 유려한 글래스모피즘 테마
- **로컬 저장**: 브라우저 로컬 저장소(`localStorage`)를 통한 설정 및 할 일 자동 저장

## 🚀 사용 방법
1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 실행합니다.
